# Changelog

## 0.1.0

- JSON suites with strict preflight validation and unique run namespaces.
- Concurrent duplicate deliveries and explicit out-of-order sequences.
- GitHub and Stripe signing with negative signature modes.
- Bounded exponential retries and capped Retry-After support.
- Read-only application-state probes and JSON pointer assertions.
- Redacted JSON and JUnit reports with CI exit codes.
- Local good/broken demo receivers and executable example suites.
